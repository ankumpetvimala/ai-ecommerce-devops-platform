# AI-Powered E-Commerce DevOps & Cloud-Native Delivery Platform

## Project Overview

This project builds an integrated DevOps and cloud-native delivery ecosystem around the existing Saleor e-commerce application.

## Objectives

- Version control with Git and GitHub
- Bash-based operational automation
- Docker and Docker Compose
- Jenkins CI/CD pipelines
- Terraform infrastructure provisioning
- Ansible configuration management
- Kubernetes orchestration and Helm packaging
- Prometheus and Grafana monitoring
- Centralized logging with ELK
- DevSecOps security checks
- Cloud deployment
- AI-assisted log and incident analysis

## Application

Saleor is used as the existing e-commerce application. Its source repository is maintained separately from this DevOps implementation.

## Repository Structure

- `scripts/` — Bash automation
- `docker/` — Container-related configuration
- `jenkins/` — CI/CD pipeline resources
- `terraform/` — Infrastructure as Code
- `ansible/` — Configuration management
- `kubernetes/` — Kubernetes manifests
- `helm/` — Helm charts
- `monitoring/` — Prometheus and Grafana
- `logging/` — Centralized logging
- `security/` — Security checks
- `docs/` — Architecture and implementation documentation
- `ai/` — AI-assisted incident analysis
